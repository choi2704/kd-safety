(주) 강동자바라 안전교육 회의록 프로그램

추가 기능
- 기본 참석자 13명 이름/직함 자동 입력
- 날짜별 회의록 저장
- 저장된 회의록을 월간 달력에서 확인
- 기록이 있는 날짜는 달력에서 표시
- 날짜 클릭 → 내용 보기 / 불러와서 인쇄
- 같은 날짜를 다시 저장하면 기존 회의록 덮어쓰기 확인
- 날짜별 주차 안전교육 내용 자동 변경
- 참석자 및 관리자 서명
- A4 한 장 출력, 참석자 한 줄 2명 배치

기본 참석자:
신종국 부장, 이창신 부장, 이창호 부장, 최태영 부장, 김황용 부장,
박영수 부장, 이승섭 부장, 윤영식 과장, 홍종택 과장, 문희민 과장,
한대화 과장, 방승일 대리, 마점수 기사, 빌알 기사

저장 위치:
회의록은 사용하는 브라우저의 localStorage에 저장됩니다.
다른 PC/브라우저에서는 기록이 자동 공유되지 않습니다.

- A4 참석자 명단을 한 줄에 3명씩 배치하고 출력 여백/간격을 줄였습니다.
