안전교육 회의록 프로그램 - 주차별 자동교육 버전

- 날짜를 선택하면 해당 주차에 맞는 안전교육 주제, 교육내용, 강조사항이 자동으로 변경됩니다.
- 8개 안전교육 주제를 순환하여 매주 반복 사용합니다.
- 교육내용과 강조사항은 필요하면 직접 수정할 수 있습니다.
- '이번 주 교육내용 불러오기' 버튼으로 기본 내용을 다시 불러올 수 있습니다.
- 참석자 및 관리자 서명을 마우스/터치로 입력할 수 있습니다.
- 회의록은 브라우저에 저장되며 A4로 출력할 수 있습니다.
- GitHub Pages 배포 시 index.html을 저장소 루트에 업로드하면 됩니다.
